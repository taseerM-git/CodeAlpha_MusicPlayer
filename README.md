# CodeAlpha Music Player

A responsive Music Player built with **HTML, CSS, and JavaScript** as part of the **CodeAlpha Frontend Development Internship**.

#Features

Play and pause music
Next and previous track controls
Playlist support
Display song title, artist, and album cover
Progress bar with current time and duration
Volume control
Autoplay next song
Responsive design

#Technologies Used

HTML5
CSS3
JavaScript
Font Awesome

#How to Run

1. Clone or download the repository.
2. Open the project in VS Code.
3. Launch `index.html` using Live Server.

Developed as Music Player for the CodeAlpha Frontend Development Internship.
